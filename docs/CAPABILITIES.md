# 能力与边界

## 当前能力

- 节点登记、连接核验、资源观察、模型和镜像管理。
- 部署、诊断、候选比较及有界质量与性能测试。
- 任务授权、资源配额、候选冻结、操作状态与清理核验。
- 使用已登记执行器进行受限源码编辑、构建和测试。
- Harness 主控及按证据准入的 Infra/Repo 专家协作。

## 仍需完成

- 跨机在线 PD、KV 传输和 Ray 联合部署的正式执行及实机验收。
- 通用 GPU 自动 profiling、算子优化及独立数值和性能验证。
- 更多模型、加速平台、多卡组合与长时间运行验证。
- 更大规模的独立评测和同条件外部基线对照。

已有 CPU、容器或单机实验不代表上述场景已经通过。运行前应核验当前节点状态、模型资产、设备权限和配方兼容性。
