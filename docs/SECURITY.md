# 数据与凭据管理

`.env.example` 与 `infra.env.example` 是不含凭据的模板。实际密钥、服务器地址、账号和指纹应在本地配置或通过工作台登记，不能写入示例文件、测试、截图或文档。登记的凭据与运行状态位于本地私有目录，备份时也应按私有数据处理。

模型权重、工作区、任务日志、会话记录和临时报告默认不提交。发布前先暂存待发布内容，运行 `python scripts/check_publication.py` 检查常见的私有路径、密钥格式和 URL 中的凭据，再人工复核暂存内容与 Git 历史。自动检查不能识别所有私有信息；`.gitignore` 也不会自动移除已经被跟踪的文件。如果凭据曾进入 Git 历史，应先撤销或轮换，再处理历史。

在服务器上执行任务前，应核验目标身份、资源占用和授权范围。连接测试或资源登记本身不授予执行权限；操作结果未知时先核对原操作，避免重复执行。
