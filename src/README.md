# src

Python 包源码：Host、业务服务、节点执行、验收和兼容入口。

## 子目录

| 目录 | 内容 |
| --- | --- |
| [infra_pilot](infra_pilot/README.md) | 独立的训练与推理环境实验入口，使用受限配方。 |
| [pilot_apps](pilot_apps/README.md) | 模型应用计划、工作区、生命周期和验收。 |
| [pilot_collab](pilot_collab/README.md) | 协作状态、历史记录与保留的实验协议。 |
| [pilot_core](pilot_core/README.md) | 配置、模型协议、执行隔离与公共存储。 |
| [pilot_delivery](pilot_delivery/README.md) | 模型引擎、预览和交付协议。 |
| [pilot_eval](pilot_eval/README.md) | 领域评测、预算准入、评分和报告。 |
| [pilot_host](pilot_host/README.md) | 官方 Host 装配、业务桥接和命令行入口。 |
| [pilot_infra](pilot_infra/README.md) | 服务器、资产、任务、节点执行、源码构建与推理验收。 |
| [pilot_projects](pilot_projects/README.md) | 项目登记、资源预检、源码快照和模型接入。 |
| [repopilot](repopilot/README.md) | 仓库修复实验、检索、工具和验收入口。 |
