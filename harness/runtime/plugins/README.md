# plugins

Pilot 的业务工具、策略和界面插件。

## 子目录

| 目录 | 内容 |
| --- | --- |
| [brand](brand/README.md) | 产品外观、标识和界面样式插件。 |
| [context](context/README.md) | 会话上下文适配插件。 |
| [delivery](delivery/README.md) | 模型交付工具和状态插件。 |
| [delivery-ui](delivery-ui/README.md) | 模型交付界面及预览通信插件。 |
| [execution-sandbox](execution-sandbox/README.md) | 执行沙箱策略插件。 |
| [history](history/README.md) | 会话历史隔离插件。 |
| [host-settings](host-settings/README.md) | 主控配置、密钥读取和设置界面插件。 |
| [infra-domain](infra-domain/README.md) | 推理任务领域接口与工作台插件。 |
| [infra-tools](infra-tools/README.md) | 基础设施领域工具插件。 |
| [intent-router](intent-router/README.md) | 业务意图识别与路由插件。 |
| [model-assets](model-assets/README.md) | 模型资产工具插件。 |
| [policy](policy/README.md) | 权限与执行策略插件。 |
| [repo-tools](repo-tools/README.md) | 仓库和源码操作工具插件。 |
| [tool-system](tool-system/README.md) | 工具与 MCP 服务配置插件。 |
| [workspace](workspace/README.md) | 工作区登记、选择和目录管理插件。 |
