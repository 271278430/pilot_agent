# tool-system

工具与 MCP 服务配置插件。

## 文件

| 文件 | 内容 |
| --- | --- |
| [README.md](README.md) | 本目录的用途和文件索引。 |
| [cli.mjs](cli.mjs) | 对应功能的 Node 命令行入口。 |
| [client.js](client.js) | 对应功能的浏览器界面和交互。 |
| [config.mjs](config.mjs) | 配置相关的 Node 模块。 |
| [index.mjs](index.mjs) | 插件或模块的注册入口。 |
| [package.json](package.json) | Node 包信息、入口或依赖声明。 |

目录内容调整后，运行 `python scripts/update_directory_readmes.py` 更新索引。
